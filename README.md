## Установка и запуск

Требования
- Python 3.12 или выше
- uv

### Установка

Клонируйте репозиторий и перейдите в папку проекта: git clone <ссылка-на-репозиторий>
cd primitive_db

Установите зависимости: uv sync

### Запуск

Запустите приложение:uv run database

Проверка кода

Проверьте код с помощью Ruff: uv run ruff check .

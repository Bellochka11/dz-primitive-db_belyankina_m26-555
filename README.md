## Установка и запуск

Требования
- Python 3.12 или выше
- uv

### Установка

Клонируйте репозиторий и перейдите в папку проекта: git clone <ссылка-на-репозиторий>
cd primitive_db

Установите зависимости: uv sync

### Запуск

Запустите приложение:uv run database

Проверка кода

Проверьте код с помощью Ruff: uv run ruff check .

## Управление таблицами
База данных позволяет создавать, просматривать и удалять таблицы. Метаданные таблиц сохраняются в JSON-файле 'db_meta.json'l.

### Описание команд
'create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ..' - cоздать таблицу
'list_tables' - показать список всех таблиц
'drop_table <имя_таблицы>' - yдалить таблицу
'exit' - выход из программы 
'help' - справочная информация 

### Пример использования
Запустите программу в терминале: uv run database

Создайте таблицу 'users':
Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

Посмотрите список таблиц:
Введите команду: list_tables
- users

Попробуйте создать таблицу с тем же именем:
Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

Удалите таблицу:
Введите команду: drop_table users
Таблица "users" успешно удалена.

Для просмотра доступных команд введите 'help', а для выхода из программы - 'exit'.
